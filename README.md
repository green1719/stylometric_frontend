# Лабораторная работа № 5: Разработка базового SPA на React

## Описание страниц и компонентов

### 1. Страница плитки

Главная страница приложения для просмотра корпуса текстовых образцов в виде сетки карточек.

* **Поля и элементы:**
  * **Фильтр-слайдер** («Длина предложения — не больше»): ползунок выбора максимальной средней длины предложения в диапазоне от 4 до 30 слов.
  * **Текстовый вывод значения:** отображает выбранное ограничение длины предложения в словах.
  * **Кнопка поиска:** круглая кнопка с иконкой лупы открывает дополнительные условия фильтрации.
  * **Дополнительные фильтры:** выбор темы текста, поле поиска по автору или фрагменту и кнопка «Сброс».
* **Карточка текстового образца:**
  * Содержит локальное изображение либо серую заглушку `default-image.svg`, тему, автора, среднюю длину предложения и количество отметок.
  * Клик по карточке открывает выбранный текстовый образец в детальном просмотре.
  * Данные карточек загружаются исключительно из локальной TypeScript-коллекции `TEXT_SAMPLES_MOCK`; запросы к серверу и базе данных не выполняются.

### 2. Страница ленты

Полноэкранный просмотр текстовых образцов в стиле вертикальной ленты.

* **Поля и элементы:**
  * **Медиаплеер:** фоновое локальное видео `default-video.mp4`; если у образца нет видео, используется видеозаглушка проекта.
  * **Заголовок и показатели:** отображаются автор текста, фрагмент, средняя длина предложения, частота союзов и количество отметок.
  * **Кнопка «Далее»:** переключает на следующий текстовый образец и после последнего возвращается к первому. При переключении обновляется маршрут `/feed/:id`.
  * **Блок фрагмента:** показывает анализируемый отрывок текста; длинный текст можно раскрыть стандартным элементом просмотра.
  * **Лайк:** показан как локальный показатель карточки без запроса к серверу.

### 3. Страница входа

*Примечание: в рамках лабораторной работы № 5 маршрут страницы входа отключён, а пункт «Вход» в нижней панели неактивен. Подключение API авторизации не входит в объём данной работы.*

В полной версии системы страница предназначена для входа пользователя и содержит:

* **Форму авторизации** с полями логина и пароля.
* **Кнопку «Войти»** для проверки учётных данных и создания пользовательской сессии.

### 4. Страница добавления текстового образца

*Примечание: в рамках лабораторной работы № 5 маршрут страницы добавления отключён, а пункт «Добавить» в нижней панели неактивен. Создание образцов требует API и авторизации, которые на этом этапе не подключаются.*

В полной версии системы это интерфейс создателя для подготовки нового текстового образца. Страница должна содержать:

* **Загрузку медиафайлов:** выбор изображения и видео с локального устройства.
* **Форму параметров:** поля автора, текста, темы и стилометрических характеристик образца.
* **Кнопки управления:** «Далее» для сохранения черновика и «Опубликовать» для размещения образца в общем корпусе.

## Используемые технологии

Приложение разработано на React, TypeScript, Vite и React-Bootstrap. Redux и собственный React Context не используются. Медиафайлы и mock-данные находятся в проекте, поэтому приложение демонстрируется без бэкенда.

## Запуск

```bash
npm install
npm run dev
```

После запуска приложение доступно по адресу, указанному Vite в терминале.
