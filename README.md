# Стилометрия — лабораторная работа № 6

React + TypeScript + Vite, Redux Toolkit, Axios и клиент, сгенерированный из Swagger. Это отдельный фронтенд для [веб-сервиса Stylometric](https://github.com/green1719/stylometric).

## Запуск

```bash
npm ci
npm run dev
```

Откройте <http://localhost:3000/grid>. Для работы с реальными данными запустите бэкенд Stylometric и его PostgreSQL, Redis и MinIO по инструкции в репозитории веб-сервиса. Vite направляет `/api` на `http://localhost:8080`, а `/s3` — на `http://localhost:9000`; адреса можно изменить в `vite.config.ts`.

Для проверки сборки: `npm run build`. Повторная генерация клиента: `npm run api:generate` (исходная схема находится в `openapi/swagger.json`).

## Что показать в лабораторной

1. Остановите бэкенд, оставив Vite включённым. Откройте `/grid` и `/feed`: гостю доступны карточки из `src/data/samples.mock.ts`. В DevTools → Network покажите неудачный запрос `/api/samples` и загрузку модуля `samples.mock.ts`. На самих страницах технические сведения об источнике данных не отображаются.
2. Запустите бэкенд. Обновите `/grid`, покажите запрос с параметром фильтра и карточки веб-сервиса. Через `/login` войдите и покажите страницы `/add`, `/feed`, `/sample/:id`, создание и публикацию образца, лайк и удаление своего образца.
3. После изменения записи в PostgreSQL обновите страницу и покажите изменённые данные. Для демонстрации входа покажите `auth` в Redux DevTools, сохранённый JWT в Application → Local Storage и состояние Redux после F5; Redux снова начинает с гостевого состояния, хотя запись в Local Storage сохраняется.
4. В коде покажите `src/app/store.ts`, срезы `src/features`, тематические `createAsyncThunk` в `src/features/samples/samplesThunks.ts`, `src/shared/api/generated/stylometryApi.ts` и исходную Swagger-схему. В Network покажите `/api/...` и `/s3/...` через прокси.

## Устройство

- `auth`, `filters`, `samples`, `ui` — срезы Redux Toolkit. Фильтры сбрасываются после выхода; при обращениях к API анимация блокирует действия пользователя.
- Доменные запросы идут из thunk через сгенерированный Swagger Axios-клиент; вход и выход выполняются отдельными вызовами Axios без thunk и кодогенерации.
- При недоступном API только гость получает локальные mock-образцы. Для вошедшего пользователя показывается ошибка запроса.
- JWT сохраняется в Local Storage, но Redux-состояние при перезагрузке страницы автоматически не восстанавливается. Не публикуйте действующий JWT на скриншотах и в репозитории.
- Изображения и видео из MinIO проходят через `/s3`; пустые адреса заменяются локальными файлами из `src/assets`.

Демонстрационные скриншоты делайте из работающего приложения: старые скриншоты ЛР 5 и собранные файлы `dist` в эту ветку не входят.
