# Стилометрия — фронтенд ЛР 5

SPA реализовано на React, TypeScript, Vite и React-Bootstrap. Данные берутся только из локальной коллекции `src/data/samples.mock.ts`: обращения к API отсутствуют, поэтому вкладка Network в браузере не показывает запросов к веб-сервису.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Страницы и элементы

| Страница | Маршрут | Что есть на странице |
| --- | --- | --- |
| Плитка | `/grid` | Компактный фильтр длины предложения; круглая кнопка поиска открывает выбор темы, поиск по автору или фрагменту и сброс. Карточки открывают отдельный образец. |
| Лента | `/feed/:id?` | Одна карточка образца, стилометрические показатели, отметки, кнопка «Следующий образец». |
| Карточка образца | `/sample/:id` | Полный текст, изображение, блок видео и кнопка перехода в ленту. |

Нижняя панель всегда содержит четыре пункта: «Лента», «Добавить», «Плитка», «Вход». В ЛР 5 доступны только «Лента» и «Плитка»; два остальных пункта визуально отключены, потому что авторизация и создание образца относятся к подключению API в следующей работе.

## Mock и изображения по умолчанию

Коллекция `TEXT_SAMPLES_MOCK` строго типизирована интерфейсом `TextSample`. В демонстрационных данных шесть образцов, и у каждого отсутствует адрес изображения. Компонент `SampleCard` выбирает `sample.imageUrl?.trim() || defaultImage`, поэтому все карточки показывают одну локальную серую заглушку `src/assets/default-image.svg`. `FeedPage` и `SamplePage` выбирают локальный `src/assets/default-video.mp4`, если `videoUrl` отсутствует; `src/assets/default-video.svg` остаётся его постером. Все CSS и media-ресурсы находятся внутри `frontend/`, поэтому проект можно открыть отдельно от родительского каталога.

## Компоненты и props

`SampleFilter` — презентационный компонент: он получает через props текущее значение поиска, максимальную длину, тему и функции их изменения. Состояние и фильтрация остаются в родительской `GridPage`. `SampleCard` получает один объект `sample` и формирует карточку. Такое разделение позволяет переиспользовать UI без дублирования бизнес-логики.

## Используемые хуки

- `useState` хранит условия фильтра и текущий элемент ленты.
- `useMemo` пересчитывает список после изменения условий фильтра.
- `useEffect` синхронизирует карточку ленты с параметром `id` в адресной строке.
- `useParams` читает `id` из маршрута.
- `useNavigate` программно открывает следующий элемент ленты.

## Ответы на контрольные вопросы

React описывает пользовательский интерфейс через компоненты. Компонент — функция, которая возвращает React-элементы; элемент — неизменяемое описание того, что React должен отрисовать. Props передают данные от родителя ребёнку и не изменяются самим ребёнком; состояние хранит изменяемые локальные данные и изменяется через setter из `useState`.

`useEffect` выполняет побочный эффект после отрисовки, а его массив зависимостей определяет, при каких изменениях эффект повторяется. В функциональных компонентах он заменяет типичные фазы жизненного цикла классов: выполнение после монтирования и реакцию на изменения зависимостей. Vite запускает быстрый сервер разработки и собирает оптимизированные файлы; Babel преобразует современный JavaScript и JSX в код, понятный браузеру.

## Сценарий показа

1. Открыть `/grid` и `/feed`, показать mock-коллекцию в исходном коде и вкладку Network после обновления страницы: там есть только загружаемые локальные файлы приложения, без запросов к API.
2. Открыть карточки № 2, № 3 или № 4: при пустом поле изображения либо видео используются локальные заглушки из `src/assets/`.
3. Показать `SampleFilter.tsx`, передачу props в `GridPage.tsx`, затем `useState`, `useMemo`, `useEffect`, `useParams` и `useNavigate`.
4. Открыть этот README.
